  #### JAVA插件一体机

 ##### **使用说明**

1：fork本项目

2：在Actions菜单允许 `I understand my workflows, go ahead and enable them` 按钮

3: 击下方文件名直达文件
- [config.yml](./src/main/resources/config.yml)

4: 修改config.yml文件里的环境变量，不需要的留空，保存后Actions会自动构建

5: 等待2分钟后,在右边的Release里的Latest Build里下载jar结尾的插件文件上传至根目录plugins文件夹启动即可(没有则手动创建文件夹)
